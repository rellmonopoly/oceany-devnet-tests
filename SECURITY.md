# Security and privacy for public tests

This is a public repository. Do not open a public issue or pull request containing credentials, recovery phrases, keypair files, signed wallet challenges, customer information, payment records, private staging URLs, or raw NFC identifiers. Use only synthetic devnet data and keep detailed QA evidence in a private record.

If you discover a security issue in Oceany, report it through the private security reporting channel of the application repository rather than disclosing exploit details here. Do not use this test repository to deploy contracts, trigger marketplace payments, or store production configuration.
